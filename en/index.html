Pipeline

From one sentence to an answer you can check

Each step can fail, and the system is built to say so rather than go quiet.

Embed the text

gemini-embedding-001 at 1,536 dimensions, matching the column that already existed, so no data migration was needed.

Store and index

The vector lives in Postgres with an HNSW cosine index, so retrieval stays fast as a user's collection grows.

Retrieve the relevant entries

The question is embedded with the same model, then one SQL function combines vector similarity with a keyword weight.

Apply a floor

Anything below 0.6 is dropped, so the answer is not grounded in an unrelated entry just to fill the context window.

Answer from the context only

The model receives the five retrieved entries and an instruction to stay inside them, rather than inventing detail.

Retrieval

Chosen from constraints, not from fashion

HNSW

Why not brute force

One table and one index mean retrieval does not scan everything, so latency holds as a user's data grows.

0.6

Tuned down from 0.7

At 0.7 the entries that should have matched were cut too often; at 0.6 wrong answers fell without adding noise.

hybrid

Keywords plus meaning

Thai text and proper nouns still need exact matches, so the same function weights keyword hits alongside vector similarity.

Models

Three roles, one adapter

Model names are read from the environment on every call, so a provider change is a config change.

RoleModelWhy
Embeddinggemini-embedding-0011,536 dimensions matches the existing column and handles Thai
Chatgemini-3.5-flashReached through an OpenAI-compatible endpoint, so swapping providers stays cheap
Imagegemini-3.1-flash-imageIllustrates a mood summary; bounded by the plan's quota

When the provider fails

Failures are split into malformed requests, refused permissions and exhausted quota, each returning a message the user can act on while the rest of the screen keeps working.

When embedding fails

The entry is saved before the model is called, so a failed embedding never costs the user their text, and the index can be rebuilt later.

Privacy

Seven pieces of personal data, and where they leave

Every time a user's text is sent to the AI provider, a consent check runs first.

What is actually enforced

Consent is required before the first AI feature, can be withdrawn in settings, and every row is guarded by row-level security bound to auth.uid() rather than a filter in application code.

Verified by TC-18 and UAT-07

Evidence

What was measured, and what was not

Measured

Search p95 of 3.16 s from 20 questions over 30 entries · grounding checked by hand · 22 automated tests passing in CI on every push.

Not measured

There is no labelled evaluation set yet, no load test at production size, and the image feature is bounded by the provider's quota, so it cannot be measured consistently.

Limits

What is not finished

The system was built by one developer, the dataset used for measurement is small, and no testing with real users has taken place. The performance figures are an early indicator, not a guarantee at production scale. Every limitation is recorded in the project documents.
